## Why this repo is PRIVATE

Public GitHub cannot stop copy-paste. Protection = **access control**:

| Layer | What we do |
|-------|------------|
| Visibility | This repo stays **private** forever |
| Public proof | Screenshots on profile README + live screen-share |
| Hiring access | Temporary collaborator invite (48h) or walkthrough |
| Secrets | Never commit `.env`, SMS keys, DB dumps, customer PII |

## Safe public surface

- Profile README module screenshots (1920 desktop)
- Live product demo by appointment
- Architecture notes only — no full tree on public GitHub

## Never push publicly

- Full `adminpanel/` tree (Teklif Robotu, sözleşme, SMS, tahsilat, CRM…)
- Customer CRM exports / contract PDFs / uploads
- VatanSMS / WhatsApp / API keys
- Superadmin / billing / kill-switch logic

## Recruiter invite checklist

1. Confirm interview is scheduled
2. Add collaborator **read** only
3. Remove access after window
4. Prefer screen-share for first technical round
